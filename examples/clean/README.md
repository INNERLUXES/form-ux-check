# Fernhollow Library: a site whose forms follow every rule

A made-up library has a small site: a home page with a search form, and a page to ask for a reader card. Every field
has a label, the required fields say so in the label and in the markup, the email, phone and postcode fields carry
their type, autocomplete token and inputmode, the error message of the email field is linked to it, and the radio
buttons and check boxes sit in fieldsets with a legend. The report has no finding, and the run passes at every level.

```
node bin/form-ux-check.js examples/clean
```

The library, the site and every person are made up. The pages are made-up input for the tool, not code of this
repository.
